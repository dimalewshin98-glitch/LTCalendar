Система отложенного запуска нагрузочных тестов. Календарь тестов

Я как специалист нагрузочного тестирования занимаюсь автоматизацией данного процесса. В основной набор нагрузочных тестов входят довольно длительные запуски до нескольких дней.  Команде НТ необходим полноценный сервис для возможности отложенного запуска тестов и их менеджмента.

Общие требования
Система представляет собой HTTP API со следующими требованиями к бизнес-логике:
-регистрация, аутентификация и авторизация пользователей;
-приём параметров теста на запуск от зарегистрированных пользователей (тестируемая система, подаваемая нагрузка, время запуска);
-учёт и ведение списка переданных запусков зарегистрированного пользователя;
-изменение параметров запуска тестов, отмена запуска;
-параллельное отслеживание и отправка запроса на запуск нагрузочного теста внешнему сервису (черный ящик) на поднятие генератора нагрузки.

Сводное HTTP API
POST /api/user/register — регистрация пользователя;
POST /api/user/login — аутентификация пользователя;
POST /api/user/tests — загрузка пользователем теста на отложенный запуск;
GET /api/user/tests — получение списка загруженных пользователем тестов;
GET /api/user/tests/id — получение подробности по тесту пользователем;
PUT /api/user/tests/id — Изменение параметров запуска нагрузочного теста;
DELETE /api/user/tests/id — Удаление отложенного теста пользователем;

Внешний сервис
POST /api/start_test  — отложенный запуск теста с переданными параметрами в заданный момент времени;
